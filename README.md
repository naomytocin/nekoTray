# nekoTray

a hungry fat stupid cat that lives in your mac bar

you feed the cat with the food, if you dont, it get sad

beware that it sleep for a whopping 12 hours total

### installation:
1. go to releases
2. download .dmg
3. open dmg, move nekoTray into applications
4. run nekoTray

you can make it a startup process manually in the settings if you so desire.
